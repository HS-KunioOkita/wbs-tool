# UC-005: タスク間の依存関係を管理する

## アクター

- 主アクター: 利用者

## 概要・目的

タスク間に先行/後続の依存関係を追加・削除する。依存関係はガントチャート上で依存線として可視化される。

## 事前条件

- プロジェクトを開いており、対象となるタスクが 2 つ以上存在する

## 事後条件

- 成功時: 依存関係が追加または削除され、ガントチャートの依存線表示に反映されている
- 失敗時: 依存関係は変更前のままである

## 基本フロー

1. 利用者がタスクツリーまたはガントチャートから対象タスクを選び「依存関係を編集」を実行する
2. UI-005 依存関係編集ダイアログが開き、対象タスクの既存の先行・後続関係が一覧表示される
3. 利用者が依存関係を追加または削除する
4. 「保存」を実行する
5. 依存関係が更新され、ガントチャートの依存線（表示 ON のとき）に反映される

## 代替フロー

- **依存線表示が OFF の場合**: 依存関係の更新自体は内部で反映されるが、画面上の依存線は表示されない。再度 ON にすれば表示される

## 例外フロー

- 先行タスクと後続タスクが同一の場合、保存できず、エラーメッセージを表示する
- 依存関係を追加すると循環依存が生じる場合、保存できず、エラーメッセージを表示する
- 同一の先行/後続ペアが既に存在する場合、重複登録できず、エラーメッセージを表示する
