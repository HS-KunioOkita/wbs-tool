# UC-008: タスクをフィルタする

## アクター

- 主アクター: 利用者

## 概要・目的

担当者・開始日・期限・親タスクの条件でタスクをフィルタし、タスクツリーおよびガントチャートに反映する。

## 事前条件

- プロジェクトを開いている

## 事後条件

- 成功時: フィルタ条件に合致するタスクのみが画面に表示されている
- 失敗時: フィルタ前の表示状態を保つ

## 基本フロー

1. 利用者がツールバーから UI-006 フィルタパネルを開く
2. 担当者（テキスト一致）、開始日（範囲）、期限（範囲）、親タスク（指定タスク配下のみ表示）の条件を入力する
3. 「適用」を実行する
4. タスクツリーおよびガントチャートが、条件に合致するタスクのみを表示する状態に切り替わる

## 代替フロー

- **フィルタを解除**: フィルタパネルで「クリア」を実行すると条件が初期化され、全タスクが表示される
- **複数条件の組合せ**: 複数条件を同時指定した場合、すべての条件を満たすタスクのみを表示する（AND 結合）

## 例外フロー

- 条件に合致するタスクが 0 件の場合、タスクツリーは空状態を表示し、「条件に合致するタスクがありません」の案内を表示する
- 開始日範囲・期限範囲で 開始 > 終了 の入力をした場合、適用できず、エラーメッセージを表示する

## 関連インタフェース

- UI-006: フィルタパネル — フィルタ条件の入力
