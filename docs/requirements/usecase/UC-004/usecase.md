# UC-004: タスクを削除する

## アクター

- 主アクター: 利用者

## 概要・目的

既存タスクを削除する。親タスクを削除した場合、子タスクは親参照を外して残す（最上位タスクに昇格）。削除対象タスクが関与する依存関係も同時に削除する。

## 事前条件

- プロジェクトを開いており、削除対象のタスクが存在する

## 事後条件

- 成功時: 対象タスクが削除されている。子タスクは「親なし」として残る。対象タスクが関与する依存関係も削除されている
- 失敗時: タスクおよび関連データは削除前のままである

## 基本フロー

1. 利用者がタスクツリーまたはガントチャートから対象タスクを選び削除を実行する
2. 確認ダイアログが表示される
3. 利用者が「はい」を選ぶ
4. 対象タスクが削除される。子タスクの親参照が外れ最上位に昇格する。対象タスクが先行または後続として関与する依存関係も削除される
5. 画面に反映される。元の親タスク（存在した場合）の期間は再算出される

## 代替フロー

- **キャンセル**: 確認ダイアログで「いいえ」を選ぶと削除は実行されず、操作を中断する

## 例外フロー

- なし（削除は単純操作のため通常は失敗しない。SQLite 書き込みエラー等の基盤レベル例外時はエラーメッセージを表示する）
