# UC-003: タスクを編集する

## アクター

- 主アクター: 利用者

## 概要・目的

既存タスクのタスク名・担当者・開始日・期限・進捗・親タスク・説明を変更する。親タスクの期間（開始日・期限）は子タスクから自動算出されるため、直接編集できない。

## 事前条件

- プロジェクトを開いており、編集対象のタスクが存在する

## 事後条件

- 成功時: タスクの変更内容が保存され、タスクツリーおよびガントチャートに反映されている。親タスクの期間は子タスクから再算出されている
- 失敗時: タスクは変更前のままである

## 基本フロー

1. 利用者がタスクツリーまたはガントチャートから対象タスクを選び編集を実行する
2. UI-004 タスク編集ダイアログが編集モードで開き、現在の値が表示される
3. 利用者が値を変更する
4. 「保存」を実行する
5. タスクが更新され、画面に反映される。親タスクの期間は子タスクから自動再算出される

## 代替フロー

- **親タスクを変更（階層を組み替える）**: 親タスク欄を変更した場合、変更前後の親タスクの期間が再算出される
- **進捗を 100% に変更**: 進捗が 100% になったタスクは「完了」として扱われ、期限超過の視覚化対象から外れる
- **親タスクの期間を直接編集しようとする**: 親タスクの開始日・期限欄は読み取り専用とし、変更不可である旨を案内する

## 例外フロー

- タスク名が未入力の場合、保存できず、エラーメッセージを表示する
- 開始日 > 期限 となる入力の場合、保存できず、エラーメッセージを表示する
- 進捗が 0〜100 の範囲外の場合、保存できず、エラーメッセージを表示する
- 親タスク変更により循環参照（自身の子孫を親に指定）が生じる場合、保存できず、エラーメッセージを表示する
