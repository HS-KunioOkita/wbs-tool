# UC-009: タスク一覧・ガントチャートを PDF エクスポートする

## アクター

- 主アクター: 利用者

## 概要・目的

選択中プロジェクトの現在の表示状態（フィルタ・表示粒度・依存線表示）に基づき、タスク一覧またはガントチャートを PDF として出力する。

## 事前条件

- プロジェクトを開いている

## 事後条件

- 成功時: PDF ファイルが利用者の指定先（または既定のダウンロードフォルダ）に保存されている
- 失敗時: PDF ファイルは生成されない

## 基本フロー

1. 利用者がツールバーから「PDF エクスポート」を実行する
2. UI-007 PDF エクスポート設定が開く
3. エクスポート対象（タスク一覧 / ガントチャート / 両方）を選択する
4. 「出力」を実行する
5. PDF が生成され、ブラウザのダウンロード機構を通じて保存される

## 代替フロー

- **タスク一覧 PDF**: 現在のフィルタ条件で表示中のタスクを表形式で出力する（UI-008）
- **ガントチャート PDF**: 現在の表示粒度・依存線表示・フィルタを反映した状態で出力する（UI-009）
- **両方を出力**: タスク一覧とガントチャートを 1 つの PDF に複数ページとして出力する

## 例外フロー

- 対象タスクが 0 件の場合、PDF 出力を抑止し、エラーメッセージを表示する
- PDF 生成中にエラーが発生した場合、保存をキャンセルし、エラーメッセージを表示する

## 関連インタフェース

- UI-003: WBS メイン画面 — エクスポートの起点
- UI-007: PDF エクスポート設定 — 出力対象の選択
- UI-008: タスク一覧 PDF — 生成される帳票
- UI-009: ガントチャート PDF — 生成される帳票

## 関連非機能要件

- NFR-001（画面応答時間）
- NFR-002（同時タスク件数）
