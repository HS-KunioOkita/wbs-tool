# UC-001: プロジェクトを管理する

## アクター

- 主アクター: 利用者

## 概要・目的

利用者がプロジェクトの作成・編集・削除・切替を行えるようにする。1 度に表示できるプロジェクトは 1 つに限定し、複数のプロジェクトを横断する操作は行わない。

## 事前条件

- アプリが起動している

## 事後条件

- 成功時: プロジェクトの一覧および選択中プロジェクトが意図どおり更新されている
- 失敗時: プロジェクトの状態は操作前と同一である

## 基本フロー

1. 利用者が UI-001 プロジェクト選択画面を開く
2. 既存プロジェクトの一覧が表示される
3. 利用者が操作を選択する（新規作成 / 編集 / 削除 / 開く）
4. 「新規作成」の場合、UI-002 でプロジェクト名・説明を入力し保存すると、プロジェクトが作成される
5. 「開く」の場合、選択したプロジェクトを開き、UI-003 WBS メイン画面に遷移する

## 代替フロー

- **既存プロジェクトを編集**: 一覧で対象を選び UI-002 を開く。プロジェクト名・説明を編集して保存する
- **既存プロジェクトを削除**: 一覧で対象を選び削除を実行する。確認ダイアログで「はい」を選ぶと、該当プロジェクトと配下の全タスク・依存関係が削除される
- **プロジェクトを切替**: WBS メイン画面のツールバーから UI-001 へ戻り、別プロジェクトを開く

## 例外フロー

- プロジェクト名が未入力の場合、保存できず、エラーメッセージを表示する
- 存在しないプロジェクトを開こうとした場合（別経路で削除済み等）、エラーメッセージを表示し、一覧を再読み込みする

## 関連インタフェース

- UI-001: プロジェクト選択画面 — 一覧表示および操作の起点
- UI-002: プロジェクト編集ダイアログ — 新規作成・編集の入力
- UI-003: WBS メイン画面 — 「開く」操作後の遷移先

## 関連非機能要件

- NFR-001（画面応答時間）
- NFR-003（対応環境）
- NFR-004（運用環境・インフラ制約）
