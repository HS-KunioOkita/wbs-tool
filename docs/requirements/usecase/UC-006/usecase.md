# UC-006: ガントチャートを表示する

## アクター

- 主アクター: 利用者

## 概要・目的

選択中プロジェクトのタスクをガントチャート形式で表示する。表示粒度の切替（日/月）、依存線の表示切替、期限超過タスクの視覚的強調を行う。

## 事前条件

- プロジェクトを開いている

## 事後条件

- 成功時: ガントチャートが現在の表示設定（粒度・依存線表示・フィルタ）に従って描画されている
- 失敗時: ガントチャートは前回の表示状態を保つか、空状態を表示する

## 基本フロー

1. 利用者が UI-003 WBS メイン画面を開く
2. プロジェクト配下のタスクおよび依存関係を読み込む
3. 現在の表示設定（粒度・依存線表示・フィルタ）に従ってガントチャートを描画する
4. 各タスクバーは開始日〜期限の範囲で描画され、進捗（0〜100%）がバー内部の塗りつぶしとして表示される
5. 期限を過ぎたタスク（システム日付 > 期限 かつ 進捗 < 100%）はバーの色を変えて表示する
6. 依存関係は依存線として描画される（依存線表示が ON のとき）

## 代替フロー

- **表示粒度を「日」に切替**: タイムライン軸が日単位の目盛りで描画される
- **表示粒度を「月」に切替**: タイムライン軸が月単位の目盛りで描画され、タスクバーは縮尺に応じて圧縮表示される
- **依存線表示を OFF に切替**: 依存線が非表示になる
- **フィルタ適用後**: フィルタ条件に合致するタスクのみがガントチャートに表示される（UC-008 参照）

## 例外フロー

- タスクが 0 件の場合、空のガントチャートを表示し、「タスクを追加してください」の案内を表示する

## 関連非機能要件

- NFR-002（同時タスク件数）
